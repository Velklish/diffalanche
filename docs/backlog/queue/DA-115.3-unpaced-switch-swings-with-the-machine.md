# DA-115.3 · The session switch swings 79–111 ms with the machine's state in the unpaced harness, and sits at its 100 ms budget

## Context

Finding discovered while working on DA-115, which took the frame-rate limit off the perf harness (`--disable-frame-rate-limit`). The owner landed that on 2026-09-24 knowing what follows; until this entry is done, a red `Switching review sessions` line in `bun run perf` is expected ([11-perf.md](../../reference/11-perf.md), "Measured again unpaced, since DA-115").

`bun perf/compare.ts`, nine a side, the unpaced tree against the 60 Hz one, on 2026-09-24 — the switch line of each run (base → branch, difference ± what the run resolves, verdict; one- and five-minute load on 8 cores):

| Base | Time, UTC | Base → branch | Verdict | Load |
|---|---|---|---|---|
| `21cf286` | 08:42–08:45 | 85.3 → 88.8 ms, +3.5 ±9 | no difference | 5.7–9.3 / 14.1–18.7 |
| `21cf286` | 08:53–08:56 | 80.2 → 79.4 ms, −0.8 ±12.7 | no difference | 8.5–14.4 / 10.8–12.0 |

The 60 Hz base stayed at 80–85 ms in all five; the unpaced side read 79–111 over trees whose page and harness are the same (`21cf286`'s harness differs from `cd3debe`'s by timing lines only, and the branch side was `6b99da6` with the flag, `8689795` and `5bf8800`). The gate went red on the line once in four unpaced runs of the day: on `5bf8800`, 09:39–09:40 UTC at 2.4 runnable tasks per core, the repetitions read 220.2, 128.7, 216.6, 100.6 and 108.2 ms, median 128.7 against the budget of 100; the rerun of the same tree read 86.2.

**The lead, not a proven cause.** The same tree `5bf8800` with every animation and transition switched off by a stylesheet the harness added after load (a scratch change, never committed), against itself as it ships, 09:51–09:54 UTC at 7.7–13.1 / 9.5–10.5: the switch read 70.0 ms (65.8–74.9) with them off and 79.2 (62.9–135.0) with them on, −9.2 ±9.2 — no difference by a hair, the slow outliers gone with the animations; the update after an edit +10 ±22, no difference. The hypothesis is that `dcin`, the 140–160 ms entrance the switched-to review's threads and cards play, runs at the unpaced frame rate and takes the processor the second switch of the harness's pair needs. In that window the tree with animations on read 79.2, the base's level, so the 23–31 ms of the three runs against `cd3debe` is not a level of the tree: it comes and goes with the machine.

The raw samples are in DA-115's result on the bus (`da115-raw-samples.txt`, and the proof runs of `5bf8800`).
