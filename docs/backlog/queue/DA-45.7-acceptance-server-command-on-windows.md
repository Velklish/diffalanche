# DA-45.7 · The acceptance suite's web server command is a POSIX shell line that Windows cannot start

- **Order:** 355
- **Scope:** [08-ui](../../reference/08-ui.md)
- **Created:** 2026-09-29
- **Dependencies:** none
- **Parent:** DA-45
- **Cost:** major

## Context

Finding discovered while working on DA-45.6. The first `acceptance on windows-latest` run (Velklish/diffalanche#13, job 109260204434) stopped before any test ran:

```
[WebServer] $ vite build
[WebServer] '.' is not recognized as an internal or external command,
[WebServer] operable program or batch file.
Error: Process from config.webServer was not able to start. Exit code: 1
```

`webServer.command` in `e2e/acceptance.config.ts` was `bun run build … && rm -rf … && bun e2e/fixture.ts … && ./dist/diffalanche-… serve …`. Playwright starts it in the platform's shell, and on Windows `cmd.exe` reads neither `rm -rf` nor `./dist/…`.

## Work to do

- Put the four steps in one script, `e2e/serve-acceptance.ts`, which runs them without a shell and serves the binary as its child.
- Point `webServer.command` at that script.

## Out of scope

- What the suite finds on Windows once it starts: those reds become findings of DA-45.

## Verification

- `acceptance on ubuntu-latest` and `acceptance on macos-latest` stay green.
- `acceptance on windows-latest` gets past the web server, and what it reports next is recorded in DA-45.
