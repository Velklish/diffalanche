# DA-12.1 · The watcher wakes for files git ignores

- **Scope:** 05-watcher (see [reference](../../reference/README.md))
- **Created:** 2026-09-05
- **Dependencies:** DA-12

## Context

Found while building DA-12. The watcher leaves out `.git` internals, any
`node_modules`, the `exclude` globs of `config.json`, and the data directory
(`src/core/watcher/index.ts`, `repositoryIgnore`). Everything else in a
repository wakes it, which includes every build output git ignores — `dist/`,
`target/`, `bin/`, coverage reports. Each write restarts the debounce, and the
ceiling of one second (`MAX_DEBOUNCE_MS`) then forces a rescan per second for as
long as a build runs: four git processes per repository each time.

What keeps this from reaching the browser is the other end: a rescan whose
result equals what the cache held announces nothing, so a build produces work
but no events. The cost is CPU while a build runs, not a wrong review.

The fix the watcher does not have is git's own answer: `git check-ignore
--stdin -z` over the paths of one burst, once per rescan, which is one more git
process per burst and needs its own cache — the ignore rules change when a
`.gitignore` does. `git status --porcelain` is not the answer: it refreshes the
index, and the tool must never write to a reviewed repository
(`docs/SPEC.md` section 11).

## Work to do

- Ask git which of the paths that woke the watcher are ignored, before deciding
  to rescan; skip the rescan when all of them are.
- Keep the answer for the burst rather than per path, and invalidate it when a
  `.gitignore` inside the repository changes.
- Measure the cost against the budget of `docs/SPEC.md` section 6: one more git
  process on the path an edit takes.

## Out of scope

- Reading `.gitignore` files without git; git owns the rules, including the ones
  in `.git/info/exclude` and the user's global file.

## Verification

- A file written into a directory named by `.gitignore` produces no rescan; a
  file next to it does.
- The measured update after an edit stays inside the budget with the extra call
  on the path.
