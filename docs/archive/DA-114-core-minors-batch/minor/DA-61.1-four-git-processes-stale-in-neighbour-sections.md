Every one of them belongs to the watcher or the server track, both running beside
the git track in the same run, so the git worker left them alone rather than
editing across a track boundary. `src/core/change-set.ts:150` said the same and
**is** fixed, because it is the git track's own file.

Four more places carry the number and are **not** part of this.
`docs/adr/adr-010-review-task-scope.md:17`, because an accepted decision records
what was true when it was taken and is superseded, not edited (`docs/README.md`,
cross-cutting principle 2); `docs/archive/` for the same reason; and the task
cards `docs/backlog/active/DA-98-scan-routes-fan-out-unbounded.md:20,46` and
`DA-103-nested-git-directories-are-watched.md:49`, which state the cost as an
argument of their own and are owned by the passes that will close them.

The number at `docs/reference/05-watcher.md:277` sits beside a measurement —
"about 190 ms" — that was taken with four processes. Whether that millisecond
figure moved is not measured here and is written as an open question, not as a
fact.
