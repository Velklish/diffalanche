# DA-9 · Result

**Closed 2026-09-05.** Completed. `src/core/domain/` holds the rules over the storage files: `createSession(dataDir, name, base, title?)`, `useSession`, `setBase`, `listSessions` (summaries with created and updated timestamps, `current`, open and resolved counts, repositories with changes from `diff.json` or `null` before the first scan; ordered by `updatedAt`, newest first), `readSession`, `resolveSessionName(dataDir, name?)` — the shared "`--review`, else `current`, else refuse" every CLI command of SPEC section 8 needs — `assertSessionName` (lowercase letters, digits, dot, dash, underscore; `.` and `..` refused as paths), `parseBaseArgument` (`head`, `branch`, `branch:<name>`, anything else a `ref`), and `DomainError` with a code the caller reads. `useSession` writes only `current`; `setBase` and every comment write bump `updatedAt`. A session whose `review.json` is unreadable is an existing session: `createSession` refuses to overwrite it and `readSession` surfaces the StorageError naming file and field. Existence is checked inside the session lock; every write of a session's files goes through one storage path, `updateSession`, which holds the lock, bumps `updatedAt`, and calls `assertHeld` before writing; a `createSession` that loses the in-lock race gets `DomainError("session-exists")` like the ordinary case. The storage `Base` is structurally identical to core-a's `BaseSpec`.

Review by an isolated session, two rounds: round two found one critical (a broken `review.json` read as "no session", so `createSession` with the same name overwrote it and emptied its comments) and six minor (existence check outside the lock, `assertHeld` missing in two writers, a residual window in the stale-lock takeover, a listing that threw on one bad directory name, undocumented error codes, wording of DA-9.1) — fixed in `082346e` and, for the storage share, `e855f19` (integrated here after DA-8's closure: takeover verifies the moved lock's token and moves it back if foreign; `sessionExists`; per-entry warnings in `listSessionNames`). Finding DA-9.1 closed at acceptance.
