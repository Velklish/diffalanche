# DA-41 · Result

**Closed 2026-09-24.** Completed. The embedding model reaches both channels: the npm package downloads the model and this platform's ONNX Runtime native files from its version's GitHub release once, on first use, into the user cache, with progress, SHA-256 checks and one-line refusals; the binary carries both and writes them out itself; `diffalanche model pull --embedding` fetches ahead of time; the release stages nineteen assets beside the binaries in `SHA256SUMS.txt`. Nothing was published or pushed. Decisions this acceptance records:

- **`serve` prepares nothing** (the orchestrator's ruling, ADR-014 4A: on first use). The first `/api/suggest`, `suggest` or `index rebuild` does; the route answers 503 "being put in place" while the files arrive.
- **The runtime's native files live in a subdirectory of the model's directory** keyed by the runtime's version and platform, `<model dir>/onnxruntime-node-<version>-<platform>/`, so builds with different runtimes never overwrite each other — the orchestrator's reading of ADR-014 5B ("the same directory"); the ADR's text is not changed.
- **CI** — `actions/cache` of `~/.cache/diffalanche/models` and `bun run model:fetch` in the `smoke` job's binary rows and in `e2e` (approved by the orchestrator); job names and matrix unchanged.
- **Each partial file is the process's own**: `.partial-<host>-<pid>-<random>`, opened exclusively; its sha256 is checked before the rename and read back from disk after it; a rename lost to another process checks the winner. The sweep removes a partial of its own host by PID and of another host only by age (over 10 minutes).
- **Write errors** (ENOSPC, EACCES) are refused with their own sentence, apart from network errors.
- **The binary writes its embedded files out in a child process**, because reading an embedded file in a Bun binary keeps its pages resident.
- **The body is read through `getReader()`**: under Bun, `for await` over a fetch body failed 9–14 times in 40, `getReader()` 0 in 120.
- **`--external '*embedder.ts'` of DA-34 is replaced** by a worker entry of its own, `dist/embed-worker.js`, built with a Bun plugin shared by the npm bundle and the binaries.
- **`model status` shows the runtime**, and "not available on this platform" on darwin-x64 (ADR-014 3B).
- **Binary sizes** 233–290 MiB (darwin-x64 67 MiB, no model).
- **What ran**: darwin-arm64 on the worker's machine; linux-arm64 and linux-x64 in a Debian container with no network and an empty cache. **What did not**: the Windows binaries and darwin-x64 were built only, and the release workflow was never run — the owner publishes.
