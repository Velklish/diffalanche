# DA-87 · Result

**Closed 2026-09-19.** Completed. `readOnlyEnv` builds the child environment instead of inheriting it: a copy of `process.env` with every `GIT_*` key dropped, and only `GIT_CONFIG_GLOBAL` and `GIT_CONFIG_SYSTEM` put back at the platform's null device. That closes both families the card proved — the `GIT_CONFIG_COUNT` / `KEY_n` / `VALUE_n` and `GIT_CONFIG_PARAMETERS` configuration source, and the `GIT_DIR` / `GIT_WORK_TREE` / `GIT_INDEX_FILE` override of `cwd` — with one rule rather than a list, which is why the decision was taken together with DA-61 in [ADR-012](../../adr/adr-012-git-trust-model.md). `cwd` is now the only thing that says which repository is read. `resolveUser` in `src/core/config/index.ts` reads the developer's own `user.name` on purpose, does not go through this module, and is untouched.

**Verification.** Three cases in `tests/git.test.ts`, each setting the variable on `process.env` for the duration of one read. The card's suggested probe, `GIT_CONFIG_KEY_0=diff.noprefix`, was measured and discarded: it does leak through the unfixed code, but the reader takes its paths from the `---`/`+++` lines before the `diff --git` line is consulted, so the path survives and an assertion on it can never go red. What replaced it: `diff.renames=false` injected the same way, where the rename in the fixture would be reported as an addition; `GIT_DIR` pointed at a second repository, which answered with that repository's file; and `GIT_INDEX_FILE` pointed at it, which answered with the same file twice. Mutation probe by the worker: the scrub replaced by an unconditional copy — exit 1, 464 of 468, all three verdicts red. The prefix is matched with `toUpperCase()`, because git's own `getenv` is case-insensitive on Windows. That one line is **not** covered by a verdict and is not claimed to be: on the platforms this suite runs on, a lowercase `git_dir` is inert, so a test for it would pass with the fix and without it. `GIT_WORK_TREE` and `GIT_CONFIG_PARAMETERS` have no test of their own because the scrub is one loop over key names, with nothing per-variable left to assert.
